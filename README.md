# 卦例档案

一个用于 Obsidian 的六爻卦例记录插件。通过六条爻线点选录入，支持桌面和移动端，适合记录“起卦时的判断—实际反馈—复盘”。

## 使用

1. 启用插件后，点击左侧书本图标，或运行命令“打开卦例档案”。
2. 点击“新建卦例”，填写占问和起卦时间。六爻从上爻排到初爻，点击长条切换阴阳，点击右侧“动”标记或取消动爻；本卦、变卦名称与变爻即时更新。新建默认显示六个阳爻；“重置卦象”恢复全阳、无动爻。
3. 保存后，记录会成为 Vault 中的独立 Markdown 笔记。默认位置为 `玄/六爻/个人卦例`，可在插件设置中修改。
4. 在列表中搜索占问、卦名、标签、判断、反馈，或按反馈状态筛选。选择记录后可编辑、打开对应笔记，或移到 Obsidian 回收站。

时间和六爻变化时，即时计算四柱、四柱旬空、六神、纳甲、六亲、世应、伏神、卦宫宫序、六冲六合、游魂归魂、十二长生与神煞。天干和地支分别按五行着色，六神也对应五行颜色。标签、判断和反馈仍由本人填写，位于折叠区。

## 排盘约定

- 输入公历北京时间（UTC+8），支持 1900—2100 年；立春的精确交节时刻换年，各“节”的精确时刻换月，23:00 子初换日，不作真太阳时校正。新建默认时间也使用北京时间，不随设备所在时区改变。
- 采用京房八宫纳甲。六亲以本卦宫五行为基准，变卦六亲也沿用此基准；本卦、变卦各自显示世应和卦宫。缺失六亲从本宫纯卦对应爻位取伏神。
- 十二栏展示日干五行的长生、帝旺、墓、绝，不分阴阳顺逆，水土同长生于申。神煞以日支取驿马、桃花，以日干取禄神、天乙；天乙采用《增删卜易》的甲戊丑未、乙己子申、丙丁亥酉、庚辛寅午、壬癸卯巳。
- 参考图用例：2026-09-26 15:44:46、全阳且二爻动，计算得到“丙午年 丁酉月 癸卯日 庚申时”“乾为天 → 天火同人”，日空辰巳。

历法使用离线打包的 [lunar-typescript](https://github.com/6tail/lunar-typescript) 1.8.6（MIT）；纳甲、六亲、世应、六神、伏神及神煞依据[《增删卜易》](https://zh.wikisource.org/zh/增刪卜易)，卦名与八宫表按[《周易》](https://zh.wikisource.org/zh-hans/周易)核对。不同软件的换日、天乙和土长生流派可能不同，以上规则已固定并记录在新保存的笔记中。

插件只列出带 `gua-casebook: true` 标记的笔记，不会批量改写课程目录。旧卦例具备完整时间和爻值时，查看页面会按上述规则自动计算，原文件仅在点击保存后更新；原有判断、反馈、复盘继续保留。时间或爻位缺失时显示原记录并提示补齐，不猜测缺失爻。同步或外部编辑与编辑框发生冲突时，保存会停止并提示重新打开。

## 安装与开发

运行 `npm install` 和 `npm run check`。将 `manifest.json`、`main.js`、`styles.css` 放入 Vault 配置目录的 `plugins/gua-casebook` 下，再到 Obsidian 的“第三方插件”中启用。

Windows 安装 Edge 后，可运行 `npm run test:ui`。它使用实际插件编辑器和模拟的 Obsidian 宿主接口，在独立浏览器中测试自动排盘、逐字五行色、日期变更、点选、键盘、保存、重新编辑及取消，并生成 `qa/` 下的窄屏与深色截图；测试不访问真实 Vault。这不等同于手机 Obsidian 真机测试。

插件使用 Obsidian Vault API 存储，不依赖桌面端文件系统接口。每条卦例独立成文件；如使用 Obsidian Sync 或其他文件同步方式，同步该笔记文件夹即可。
